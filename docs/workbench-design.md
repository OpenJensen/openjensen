# Workbench presentation

OPEN JENSEN uses a shared visual system for the workspace and API reference: cool neutral surfaces, a restrained blue selection color, readable stage headings, consistent control spacing, and matching light/dark tokens. Focus indicators, reduced-motion preferences, existing accessible control names, and narrow-screen wrapping remain part of the shell. On narrow screens, lifecycle navigation becomes a horizontally scrollable keyboard-accessible strip, while project selection and creation share a compact row. Color indicates recorded state; decoration does not imply connectivity or model quality.

Each stage explains its purpose. Distillation remains labeled planned until its application workflow exists. The interface retains the distinction between engine execution checks, scored evaluation, native simulation, and download-only packed policies.

Native simulation separates reviewing work from preparing another paid run. Selecting a recorded job brings its status and video ahead of the preparation form. Pickup success and calibration stay explicitly unmeasured/unverified. Known worker states remain visible while activity, identity, and raw reports live in an expandable technical section. Polling preserves the user's disclosure choice. Failed activity refreshes leave a visible stale-state notice alongside cached worker observations, even when technical details are closed. The new-run form remains reachable by keyboard and retains source/profile selection, timeout bounds, ambiguous-submission handling, and explicit paid-run consent; no launch occurs on navigation.

Desktop/mobile browser checks cover existing import, training, quantization, simulation, cloud, teaching, theme, and API-reference actions. Additional tests verify result-before-preparation order, keyboard disclosure controls, unchanged consent, and activity polling without reopening technical details. Visual review uses the actual production export on a temporary local workspace; result-layout previews use explicitly generated API/media fixtures and are not robotics evidence.
