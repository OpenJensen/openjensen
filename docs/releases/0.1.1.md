# OpenJensen 0.1.1

Release candidate; publish after the remaining Robot Lab changes and PRs are
integrated and the exact release commit passes CI. The latest published release
is currently v0.0.1; there was no published v0.1.0 release.

## Changes since v0.0.1

- SO-101 Robot Lab: motor identification and mapping, calibration, 3D joint
  selection, on-screen joint sliders/steps, camera preview and LeRobot v3 recording.
  Managed companions support macOS and Linux; USB devices stay on that computer.
- Settings → Modules: add/hide optional pages and install isolated runtime
  dependencies with progress, cancellation and retry. Training uses the existing
  local NVIDIA worker setup. External providers, companion pairing and Isaac
  configuration retain their own setup actions.
- Header version information and confirmed updates from upstream main, including
  workspace backup, restart validation, rollback and connection-loss recovery.
- Dataset library and local-format imports, clearer model/compute selection,
  training progress, quantization comparisons and package-size reporting.
- Workspace navigation, mobile layouts, concise interface copy and public/private
  gateway boundaries.

## Upgrade

Finish active jobs and release robot motors. Preserve a stopped-workspace backup
and the previous application runtime; follow [the upgrade guide](../upgrading.md).
Existing projects, datasets, models and configuration stay in the persistent
workspace. `firebird` and `FIREBIRD_*` remain compatibility aliases.

The browser updater tracks main commits rather than release tags. From another
device, installation updates the named application server. Mac/Linux companions
are updated on their USB computer through their managed installer.

This is a source release. Core uses Python 3.14.7; web builds use Node 24.21 and
pnpm 12.6.0. Native training, simulation and other workers retain their separate
runtimes. Desktop version metadata is aligned; publishing this release does not
establish a new self-contained desktop installer or fresh GPU/simulator acceptance.
