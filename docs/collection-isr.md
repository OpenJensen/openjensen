# Comparing ISR with and without Astra traces

In Robot Lab → Astra collection, enter the fixture configuration and success criterion under Experiment settings. Use a configuration inventory that specifies the block and tray starting poses, arm mounting and camera placement. Record the same frozen configuration ID across repetitions. The collection API also accepts `experiment.attempt`, `subtask` and `parent_run_id`. A replay is a new acquisition, with new images, measured actions, episode ID and outcome. Its source family is inherited. Offline augmentations must inherit both the family and fixture IDs.

## Raw episode v2

The existing LeRobot rows, paired lossless PNGs, command receipts, model observation JPEGs and tool trace remain available. The regular LeRobot time axis is frame index divided by requested FPS. In the following sidecars, nanosecond integers refer to their named process clocks. Absolute Unix time is for accounting.

| Evidence under `evidence/` | Contents and limits |
| --- | --- |
| `recording.json` | Run/episode/session/family, parent, task/attempt/subtask, configuration and criterion, build and controller fingerprints, limits and nominal 40 Hz, encoder calibration, joint order/units, camera roles/shape/modes and FK chain. Missing firmware, sensor geometry, device offsets and exposure timestamps are null. XYZ is FK of measured angles on the nominal SO101, in base-link metres at the fixed gripper frame. Gripper is calibrated opening in percent, not jaw width. |
| `camera-streams.zip` and `camera-streams.jsonl` | Every frame published by either host reader during capture, including frames between paired samples and during API waits. Indexed PNGs have per-role IDs, sequence numbers and host read-completion time. Sensor exposure, upstream driver loss and force/contact are unavailable. A bounded writer overflow or device failure stops collection and marks partial evidence. |
| `frames.jsonl`, `controller.jsonl` | Each pair has its two independent frame IDs, host arrival and recorder availability, pair skew, reader skips, missed schedule count and the original feedback/write sample. Controller rows separately record calibrated feedback, hold/executing state, raw motor ticks and normalized targets actually sent. Dispatch and completion bracket the host control operation. The bus does not acknowledge each motor goal. |
| `trace.jsonl`, `observations/`, `executions/` | Public model/tool inputs and outputs, observation references, validation captures, durable command ID, deduplication, approval, acceptance, segment start, writes, measured completion or abort/rejection. Request/response boundaries measure provider-call elapsed time including local SDK overhead. Synthetic delay has separate start/end events. Node hrtime and application/robot clock probes permit alignment with empirical uncertainty. Raw probes remain available to re-estimate offsets. Offset bounds depend on stable clocks between probes. A pending API call and a moving arm can overlap. |
| Dwell and review | The `dwell` tool declares duration and purpose and maintains existing control supervision. Completion within encoder tolerance, a planned grasp-settling hold and physically verified settling are distinct. Raw outcomes default to unknown. Operator annotations can mark clean success, recovery, failure, intervention, reset or unknown and cite frame ranges, note, confidence and optional measured reset minutes. Use POST `…/collection-runs/{run}/annotate` with `label, first_frame, last_frame, note, confidence`. Reviews after finalization are separate immutable overlays available via GET `…/{run}/reviews`. Raw evidence remains sealed. |
| `seal.json` | SHA-256 of every raw file. The private library adds its own source and annotation metadata. The exporter checks the complete raw inventory. A seal detects accidental modification; it is not a signature. Old episodes remain readable in the library and are ineligible for v2 timing claims. |

## Offline views

Use the repository Python environment to collect a disposable test episode. Use the CPU dataset reader with NumPy and Pillow to verify and generate views. Point `JENSEN_PI_NODE` to Node 24, run `npm ci` in `workers/pi_collection`, and set `JENSEN_COLLECTION_PYTHON` and `FIREBIRD_CPU_READER_PYTHON` to the CPU reader. Run these commands from the checkout:

```sh
git clone https://github.com/D-Robotics-AI-Lab/ISR /tmp/isr-upstream
git -C /tmp/isr-upstream checkout d65f94cc0155d8908fd061a47b71b7370279be3f
uv run python scripts/verify_collection_isr.py capture /tmp/collection-proof
PYTHONPATH=packages/core/src "$JENSEN_COLLECTION_PYTHON" scripts/verify_collection_isr.py verify /tmp/collection-proof --upstream /tmp/isr-upstream
PYTHONPATH=packages/core/src "$JENSEN_COLLECTION_PYTHON" scripts/collection_isr.py episode.zip /tmp/isr-upstream views.json --budget 32
```

Choose the retained budget before comparing conditions. A budget below the union of mandatory upstream indices and protected dwell frames, or above the eligible count, is rejected. Omitting the budget sizes a verification fixture only. Both arms run the pinned upstream dynamic program with measured FK XYZ, irregular elapsed seconds, and gripper fraction (percent divided by 100). Both preserve its gripper-change and cluster guards. Blind fills the budget by time coverage. Assisted retains declared manipulation dwell and fills outside evidenced stable API waits first. Ambiguous and moving intervals receive no stable-wait penalty. Motion labels use joint feedback, span alignment uncertainty and the controller journal. Acceleration and distance parameters, threshold and retained counts are in the manifest. The reference CLI also rewrites action fields. This adapter uses only its index selector and reads training targets from actual motor writes. [Upstream implementation](https://github.com/D-Robotics-AI-Lab/ISR/tree/d65f94cc0155d8908fd061a47b71b7370279be3f)

The analyst manifest maps every selected sample to original elapsed time, derived time, both image IDs, command and control-sample IDs. Each action uses the first recorded dispatch after both RGB frames became available. The two student files contain one list per continuous segment, RGB paths relative to the raw ZIP, calibrated joint state, task and sent target. Form action chunks within each segment. Never concatenate segments or episodes when forming windows. Pass human review overlays with `--reviews reviews.json`. Timing gaps, invalid pair ages, missing writes, resets, failures and interventions break continuity.

For the primary comparison, assign held-out fixture IDs before processing, keep whole source families together, and quarantine missing fixture IDs. Give both arms the same eligible original runs, review decisions, per-episode budget, supervised collection/reset time, training steps, seeds and evaluation configurations. Report raw episodes excluded and why. Run the student with only RGB, proprioception and task at evaluation. No provider calls, receipts, event masks, timing labels or outcome annotations are student inputs. The synthetic fixture checks instrumentation and creates no physical task-success evidence.
