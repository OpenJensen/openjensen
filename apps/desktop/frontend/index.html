Connection help

Start the local application with firebird serve. It must also serve the built web interface. The default address is http://127.0.0.1:8000.

Use the native OPEN JENSEN → Connection menu to return here. A different local port can be selected before launch with FIREBIRD_DESKTOP_PORT.
